# Yao Jia · Academic Website

[Website](https://jurio0304.github.io/) · [GitHub profile](https://github.com/Jurio0304) · [ORCID](https://orcid.org/0000-0003-3118-3885)

Use Node.js 22. Run `npm ci` and `npm run dev` locally, or `npm run build` to export the site to `out/`.

- `content/config.toml` holds identity, links, navigation and language settings.
- `content/about/` and `content/cv/` hold the English and Chinese Markdown.
- Create one folder per publication with `entry.bib`, or per project, award or academic service with `entry.toml`. Store assets beside the entry. A first award or service entry makes its navigation link visible.

The site uses the MIT-licensed [PRISM](https://github.com/xyjoey/PRISM) template and [Qi Xiong's adaptation](https://github.com/xiongqi123123/xiongqi123123.github.io).
